# Stemit

A focused Android vocal and instrumental separator. The Android application source, build instructions, privacy summary and third-party notices are in the [Stemit directory](Stemit/).

- [Download releases](https://github.com/Augak/Stemit/releases)
- [Application documentation](Stemit/README.md)
- [Privacy summary](Stemit/PRIVACY.md)
- [Third-party notices](Stemit/THIRD_PARTY_NOTICES.md)

Stemit uses an on-device ONNX separation model. Audio is selected by the user and processed locally; the first use downloads the model. See the application README for device requirements, build commands, test coverage and known limitations.
